Base teórica

Regras ensinadas ao provador

Regras α preservam o mesmo ramo; regras β criam alternativas. T e F indicam o valor assumido da subfórmula.

α

Regras lineares

As duas consequências permanecem juntas.

T (A ∧ B)TA, TB
F (A ∨ B)FA, FB
F (A → B)TA, FB
T ¬A / F ¬AFA / TA
β

Regras ramificadas

Cada alternativa segue em um ramo.

F (A ∧ B)FA │ FB
T (A ∨ B)TA │ TB
T (A → B)FA │ TB
T / F (A ↔ B)casos concordantes / discordantes
